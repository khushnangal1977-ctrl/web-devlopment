# My First Website 🚀

A beginner-friendly static website built with HTML, CSS, and JavaScript.

## Files

- `index.html` — website structure
- `style.css` — styling and layout
- `script.js` — button interaction

## Run locally

Download or clone this repository, then open `index.html` in a web browser.

## Publish online with GitHub Pages

This repository can be hosted with GitHub Pages:

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then click **Save**.
4. Wait for deployment. The expected site URL is https://khushnangal1977-ctrl.github.io/web-devlopment/ . The URL will work after Pages deployment succeeds.
